    FAQ

    Pertanyaan yang sering muncul

    Saya sibuk kerja. Butuh waktu berapa lama sehari?

    Cukup 10 menit: cek quest hari ini, centang kebiasaan, catat pengeluaran. Game-nya opsional sebagai hadiah setelah tugas nyata selesai.

    Apakah perlu internet?

    Tidak. Semua aplikasi berjalan offline. Internet hanya untuk mengunduh file (dan membuka pertama kali di iPhone).

    Bisa dipakai di iPhone?

    Bisa. iPhone/iPad memakai versi Web App: buka link dari Safari → Bagikan → Tambah ke Layar Utama. Ikon Labo muncul di layar utama dan berjalan offline. Android memakai APK, laptop memakai versi desktop.

    Data saya disimpan di mana?

    Di perangkatmu sendiri, tidak dikirim ke server. Ada backup otomatis serta ekspor/impor CSV untuk pindah HP ↔ laptop.

    Bayar bulanan?

    Tidak. Sekali bayar, file dan aplikasi menjadi milikmu, termasuk pembaruan perbaikan untuk versi yang dibeli.

    Apa bedanya Core dan Ultimate?

    Core untuk sistem pribadi (kerja, kebiasaan, keuangan). Ultimate menambah aplikasi versi PRO, LABO Asisten (Companion), dua ebook, dan sistem perusahaan lengkap untuk yang memimpin tim atau punya usaha.

    Apakah ini menjamin saya kaya atau bebas finansial?

    Tidak ada yang bisa menjamin itu. LABORU adalah alat bantu pencatatan, perencanaan, dan edukasi. Hasil bergantung pada kondisi dan konsistensi masing-masing, dan bukan nasihat investasi/keuangan profesional.

    Instal APK aman?

    APK tidak diunduh dari Play Store, sehingga Android menampilkan peringatan standar. Panduan instal langkah demi langkah disertakan.
